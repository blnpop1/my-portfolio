## Getting Started

### Dependencies

No dependencies need to be installed.

### Installing

Download this zip file, extract it, and double-click this index.html
when prompted, choose which browser you'd like to open index.html in

### Executing program

Once you've selected the browser, it'll open it in said browser and display 
elements I created with HTML.

## Help

Ensure you have html 5 running on your browser!
Older browsers may not support some elements I have!
